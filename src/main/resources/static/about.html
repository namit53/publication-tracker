About Publication Tracker

A university research publication tracker, built as a CI/CD project. Anyone can search and browse research papers, and an admin can add papers or import them from OpenAlex.

How the pipeline works

Every push to GitHub starts an automated pipeline:

  1. GitHub Actions runs all automated tests.
  2. If the tests pass, it builds a Docker image of the app.
  3. If both pass, Render deploys the new version.
  4. If anything fails, nothing is deployed and the live site stays unchanged.

Built with

Java 25, Spring Boot, Maven, Thymeleaf, Docker, GitHub Actions, Render and the OpenAlex API.
